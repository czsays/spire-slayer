Recommendation Summary

Use Option A (pill badges) with the dimmed + dashed border treatment for disabled potions. This reuses the exact visual and interaction pattern already established by RelicPill in DeckTracker.tsx: compact rounded pills with portal-based hover tooltips. It is space-efficient for the narrow sidebar, wraps gracefully for 1-3 potions (the game maximum is typically 3 slots), and requires no new interaction patterns.

Strengths

  • Consistent with existing RelicPill pattern
  • Compact: fits 3 potions in one row at sidebar width
  • Hover tooltip reuses portal pattern from DeckTracker
  • Disabled state is accessible (not just opacity)

Trade-offs

  • Very long potion names may truncate at narrow widths
  • No room for description inline (tooltip-only)
